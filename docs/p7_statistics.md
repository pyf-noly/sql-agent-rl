# P7 统计附录：配对比较与显著性

> 2026-11-06 · 作用：把"不显著"这句话变成可复核的数字。
> 脚本：`scripts/paired_stats.py`（不需要 GPU，只读 `results/*.json`）

---

## 1. 为什么必须做配对比较

本项目所有**对照**都在**同一批 307 条题**上跑（同一 `stride=5` 抽样），
所以"准确率差多少"应该只看**不一致的样本**，而不是把两组当独立样本算方差。
（v3 的单轮主数字另外补了全量 1534 条：**50.85% ± 1.3pp**，与 307 条抽样差 0.94pp；
配对检验本身仍用 307 条的同批对照。）

- **独立样本 SE**：`sqrt(p₁(1−p₁)/n + p₂(1−p₂)/n)` ≈ 4.0pp（n=307 时）
- **配对 SE**：`sqrt(b + c) / n`，其中 b/c 是"只有 A 对"和"只有 B 对"的条数

配对把"同一道题的难度"从误差里消掉了，SE 通常只有独立样本的一半。
早前的记录里写"+2.93pp ≈ 0.7σ"用的是独立 SE（4.0pp）；**正确的配对口径是 z=1.24**。
两个都列出来，避免只挑对自己有利的那个。

---

## 2. 检验方法

McNemar 检验的原假设：b 与 c 同分布（即两组没有差异）。
在 H₀ 下 `b ~ Binomial(b+c, 0.5)`，用**精确二项检验**（不依赖大样本近似）：

```
p = 2 · Σ_{i=0}^{min(b,c)} C(n, i) / 2^n ,   n = b + c
```

差值置信区间用正态近似：`diff ± 1.96 · sqrt(b+c)/n`。
样本量估算：保持当前效应量，SE ∝ 1/√n，所以
`n_new = n · (z_target / z_current)²`
（z_target = 1.96 对应 p<0.05，2.80 对应 80% 功效）。

| 5 | v3 t3 | v3 t1 | 57.00% | 51.79% | **+5.21pp** | 16 / 0 | 1.30pp | 4.00 | **<0.001** | [+2.66, +7.77] |
| 6 | v2 t3 | v1 t3 | 55.37% | 54.07% | +2.61pp | 24 / 16 | 2.06pp | 1.26 | **0.268** | [−1.43, +6.64] |

`b` = 只有 A 对，`c` = 只有 B 对。

### 怎么读这张表

1. **只有第 5 行显著**：多轮本身（t3 vs t1）带来的 +5.21pp，p<0.001。
   这是本项目最稳的结论，和最早就观测到的现象一致（P2 的 DeepSeek +4.67pp、
   P4 的 4B +9.00pp 都在同一量级）。
2. **第 1 行（v3 vs v1，+2.93pp）p=0.272**：方向一致、CI 跨 0。
   诚实说法是"正向信号，样本量不足以定论"。
3. **第 2/3 行（轮级优势）：b+c 只有 9~10 对**。差值 +1.63pp 看着大，
   但只是因为 307 条里恰好 7 条"只有轮级对"、2 条"只有 outcome 对"。
   这正是"小样本 + 大效应量"容易过度解读的场景——**必须报 b/c，不能只报 pp**。
4. **第 4 行**验证了 mask 的有效性：v3 的 t1 与 v1 没有差异（+0.33pp，p=1.0），
   说明"mask 第一轮"没有损伤单轮能力。

## 4. 功效分析（下一轮要多少样本）

| 对照 | 当前 z | p<0.05 需要 | 80% 功效需要 |
|---|---|---|---|
| v3 t3 vs v1 t3 | 1.24 | **≈772 条** | ≈1577 条 |
| 轮级 vs outcome-only | 1.67 | ≈425 条 | ≈868 条 |
| v3 t3 vs v3 t1 | 4.00 | 已显著 | 已显著 |

**结论**：全量 t1 已经跑完（1534 条，v3 **50.85%**，CI ±1.3pp）；
但上表的对照都是 307 条上的单轮/三轮，要把它们也做全量，t3 需要 3 倍机时（约 3.2h / ¥8）。
按当前效应量，即使跑满 1534 条，
v3 的隔离效应也刚够 p<0.05 的门槛，**性价比不高**——所以项目选择停在"方向对 +
机制清楚 + 如实报告不显著"，而不是烧钱追星号。

## 5. 复现

```bash
# 单对比较（A 在前，差值 = A − B）
python scripts/paired_stats.py \
    results/baseline_bird_p6v3_t3_s5.json \
    results/baseline_bird_p6sft_t3_s5.json

# 输出示例
# EA(A) = 57.00%   EA(B) = 54.07%   差值 = +2.93pp
# 不一致对：只有 A 对 31，只有 B 对 22
# 配对 SE = 2.37pp（独立样本 SE = 4.01pp）
# z = 1.24   精确 McNemar p = 0.272   95% CI = [-1.72, +7.58]pp
```

依赖：结果 JSON 里必须有 `episodes`（含 `idx` 与 `correct`）。
所有 `baseline_bird_*_s5.json` 都满足；如果是自己新跑的结果，别删 `episodes`。

## 6. 一条方法论备注

做 Agent / RL 的小样本实验时，**"准确率差 X pp"几乎总是不足以支撑结论**。
要么报配对检验（同一批题时必须），要么报多个 seed 的均值±标准差。
本项目在 P7 阶段补上了前者——代价只是几十行脚本，但它让"不显著"从一句感觉
变成了一个可以复核的数字。
